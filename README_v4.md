# RADAR医学影像诊断平台 v4.0 专业版

## 🎉 版本更新说明

v4.0是一个重大升级版本，重点解决了之前版本界面粗糙、影像显示不专业的问题。

### ✨ 新增功能

#### 1. **专业级医学影像查看器**
- 🔵 **单视图高级查看器**
  - 基于HTML5 Canvas和现代Web技术
  - 支持平移、缩放、窗位窗宽调整
  - GPU加速渲染，流畅度高
  - 实时显示鼠标位置和像素值
  - 专业的深色医疗主题界面

- 🌐 **多视图三视图显示**
  - 同时显示轴位（Axial）、矢状位（Sagittal）、冠状位（Coronal）
  - 自动定位到中心切片
  - 网格布局，含3D体绘制预留区域

#### 2. **现代化用户界面**
- 采用渐变色设计，视觉效果更专业
- 卡片式布局，信息层次清晰
- 响应式设计，适配不同屏幕
- 悬停动效，交互体验流畅
- 统一的视觉语言和色彩系统

#### 3. **优化的功能模块**
- 📋 单例诊断：完整的影像上传、查看、诊断流程
- 📊 批量处理：支持多文件同时处理
- 📜 历史记录：完善的病例管理系统
- ⚙️ 系统设置：可配置的参数和主题

### 🚀 使用方法

#### 启动v4.0版本

**Windows:**
```bash
start_web_v4.bat
```

**命令行:**
```bash
conda activate radar
cd radar-web
python -m streamlit run app_v4.py --server.port 8504
```

#### 访问地址
- 本地访问：http://localhost:8504
- 网络访问：http://YOUR_IP:8504

### 📖 功能使用指南

#### 单例诊断流程

1. **上传影像**
   - 支持格式：NIfTI (.nii, .nii.gz), DICOM (.dcm), NumPy (.npy), PNG/JPG
   - 拖拽或点击上传
   - 自动识别文件格式

2. **选择查看器**
   - 🔵 单视图高级查看器（推荐）
     - 选择切片和视图方向
     - 调整窗位窗宽
     - 使用平移、缩放、窗位调整工具
   - 🌐 多视图三视图
     - 同时查看三个方向
     - 自动中心定位
   - 📊 传统2D查看器
     - 简单切片浏览

3. **AI诊断**
   - 点击"开始AI诊断分析"按钮
   - 等待AI模型处理
   - 查看诊断结果：
     - 诊断结论
     - 影像学发现
     - 建议处理
     - 置信度和严重程度

4. **生成报告**
   - 点击"生成PDF诊断报告"
   - 下载专业医疗报告

#### 查看器工具使用

**单视图高级查看器工具栏：**
- 🔍 平移：拖动影像移动位置
- 🔆 窗位/窗宽：拖动调整图像对比度
- 🔎 缩放：滚轮缩放影像
- ↺ 重置：恢复初始状态

**侧边栏控制：**
- 切片选择：滑块快速定位
- 视图方向：轴位/矢状位/冠状位切换
- 窗位：-1000 ~ 1000 HU
- 窗宽：1 ~ 2000 HU

**信息叠加层显示：**
- 当前切片位置
- 视图方向
- 鼠标实时位置
- 像素值

### 🔧 技术架构

#### 前端技术
- Streamlit 1.31.0 - Web框架
- HTML5 Canvas - 图像渲染
- CSS3 - 现代化样式
- JavaScript - 交互逻辑

#### 后端技术
- Python 3.10
- NumPy - 数组处理
- Matplotlib - 图表生成
- Pillow - 图像处理
- SimpleITK - 医学影像处理

#### 数据库
- SQLite - 历史记录存储
